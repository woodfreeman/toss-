# Toss 快抛

Toss 是一款面向可信局域网的自托管互传工具，优先面向 Windows 电脑，支持传送文本、图片和文件。程序运行在自己的设备上，数据保存在本机，不经过云端中转。

**源码版本：** 0.1.7（以 backend/main.py 为准）

[English](README.md) · [项目说明](PROJECT_DESCRIPTION.md) · [部署说明](部署说明.md)

## 功能

- 发送文本、多文件和图片，也可直接粘贴剪贴板截图。
- 浏览、预览、下载记录，并添加备注或重命名。
- 将条目移入回收站、还原，或彻底删除。
- 可设置访问口令，并将保留期设为 1 至 90 天（默认 30 天）。
- 显示当前实例地址，并保存另一个 Toss 实例的快捷入口。
- Windows 打包版可检查并安装上传到本实例的新版本程序。
- 可选注册为当前 Windows 用户登录时启动。

## 工作方式

可以在每台电脑上各运行一份 Toss，也可以只运行一个实例供其他设备访问。每个实例都有独立数据库和文件目录。“对方 Toss”按钮只会在浏览器中打开已保存的对方地址，不会在实例间同步或复制记录。上传的数据保存在当前提供页面的实例上。

程序默认监听本机所有网络接口的 8400 端口，以便局域网设备访问。可通过环境变量 TOSS_PORT 更改端口。

## 从源码运行

在仓库根目录安装 Python 依赖并启动：

    python -m pip install -r requirements.txt
    python backend/main.py

在本机浏览器打开 http://localhost:8400。其他设备请使用主机可达的局域网地址和端口，例如 http://<LAN-IP>:8400。Windows 防火墙询问时，只在可信的专用网络中允许访问。

在 PowerShell 中更改端口：

    $env:TOSS_PORT = "8401"
    python backend/main.py

本源码仓库不包含编译好的 exe，也未包含固定版本的发布构建配置。

## 数据与安全

- 传输记录、上传文件、SQLite 数据库、会话签名密钥和日志均保存在运行数据目录 data/ 中。
- 请保护 data/，不要将它提交到源码仓库。该目录含有用户内容和登录会话签名密钥；仓库忽略规则已排除它。
- 访问口令可选。让其他设备连接前建议设置口令。程序以 PBKDF2-HMAC-SHA256 哈希保存口令。
- 程序默认使用普通 HTTP，不启用 TLS。只在可信网络中使用；不要直接暴露到公网，也不要配置路由器端口转发。
- 程序不提供云端备份、实例间自动同步、断点续传或分块上传。

## 保留期与限制

默认保留 30 天，可在设置中调整为 1 至 90 天。保留期清理适用于普通记录和回收站记录。上传界面建议单个文件不超过 500 MB；当前不支持分块或断点续传。

## Windows 辅助脚本

install-autostart.bat 会把 Toss.exe 注册为当前 Windows 用户登录时启动；remove-autostart.bat 用于移除该启动项。两个脚本都要求 Toss.exe 与脚本放在同一目录。

打包版的一键更新仅适用于 Windows exe 运行模式。新版本程序需上传到该实例，文件名须符合 Toss-v0.1.8.exe 这样的版本格式。
